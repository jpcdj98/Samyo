# Samyo front end (HTML + CSS)

Static pages, no JavaScript yet.

- index.html, shop.html, product.html, cart.html, checkout.html, confirmation.html, orders.html
- css/styles.css: tokens, base, layout, components, pages

Back-end hooks: `<!-- BACKEND -->` comments mark where lists load; `data-product-id` and `data-order-id` carry record ids; forms already have `name` attributes and `action` targets.
